# Обвязка прогона по листам Эппа

Конвейер (`notes-omr/pipeline/`) починен по итогам прогона в двух местах —
`glyphtext.py` (аккордовый шрифт с кодировкой, объявленной именем, больше не
перекодируется по контурам) и `chords.py` (вместо признака «немецкий лист» —
`b_is_flat` про голое «B»); всё остальное здесь — обвязка вокруг конвейера.
Вне git, как и сами PDF.

- `build_queues.py` — очереди из `tiers.json` + `sheets-kind.json`; файл листа
  выбирается сверкой подтекстовки с нашим текстом, а не по имени
- `prep_root.py` — теневой ROOT с эталонами без `{…}`: латиница аккордов ломает
  буквенное сравнение в `align.fit_by_alignment`
- `run_parse.py` / `run_align.py` — разбор листа и раскладка; результат кладётся
  под **нашим** номером в `notes-omr/out-epp/`, а не под номером листа
- `chimport_batch.py` — посадка аккордов (с `fit`-раскладкой) → `chords-plan.json`
- `chimport_write.py` — выгрузка в `songs-data/songs/NNNN.txt`
- `summary.py`, `verify_high.py`, `select60.py` — сводки и выборки
- `recheck_abc.py` — сверка починенного конвейера с ранее выгруженными `out-epp/*.abc`
- `diag_recheck_diff.py` — чем именно расходятся песни из `recheck-abc.json`
- `diag_notation_scan.py` — каким набором размечена гармония листа
- `diag_bnote2.py` — признаки листа вокруг голого «B»: бемоли, диезы, слоговые ступени
- `diag_bkey.py` — ключевые знаки листов, где про «B» не говорит ничего
